# SubExchange - YouTube Creator Exchange Network

An interactive coin-based growth exchange web application for creators to exchange subscribers and watch retention fairly.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
The application will start on `http://localhost:3000` (or the port specified by Vite).

### 3. Build for Production
```bash
npm run build
```

## 🌟 Key Features
- **Fair Coin Economy**: Earn coins by watching videos for the verified retention duration.
- **YouTube Embed Player**: Interactive video countdown timer with anti-cheat protection.
- **Campaign Studio**: Launch creator subscriber and watch retention campaigns.
- **Creator Dashboard**: Real-time wallet, analytics, creator badges, and campaign management.
- **Dark/Light Theme**: Sleek YouTube-inspired interface with responsive mobile view.

## 📦 Tech Stack
- React 18
- TypeScript
- Tailwind CSS
- Lucide Icons
